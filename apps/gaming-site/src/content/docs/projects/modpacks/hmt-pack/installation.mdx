  <TabItem label="CurseForge">
    <Tabs>
      <TabItem label="On the app">
        1. Download, install and launch [CurseForge
        App](https://www.curseforge.com/download/app#download-options) * On
        Windows, the standalone version is recommended. 2. Select _Minecraft_
        from the grid or sidebar 3. Search "HMT Pack" 4. Click `Install` *
        Optional: Select the version you want by instead clicking the row →
        `Versions` → `⤓`. 5. To run the modpack, hover on the modpack icon and
        click `Play` 6. Once the Minecraft Launcher has opened, click `Play`
        again
      </TabItem>
      <TabItem label="On the website">
        1. Download and install [CurseForge
        App](https://www.curseforge.com/download/app#download-options) * On
        Windows, the standalone version is recommended. 2. Go to [the HMT Pack
        listing page](https://www.curseforge.com/minecraft/modpacks/hmt-pack) on
        CurseForge 3. Click `Install via App` and accept the prompt in your
        browser * Optional: Select the version you want by instead clicking
        [`Files`](https://www.curseforge.com/minecraft/modpacks/hmt-pack/files/all?page=1&pageSize=50&showAlphaFiles=show)
        → the version you want → `Install`. 4. The app should open and download
        should start 5. To run the modpack, hover on the modpack icon and click
        `Play` 6. Once the Minecraft Launcher has opened, click `Play` again
      </TabItem>
    </Tabs>
  </TabItem>
  <TabItem label="Modrinth">
    <Aside>
      HMT Pack has not been approved by Modrinth yet and cannot be installed
      there.
    </Aside>
  </TabItem>
      <TabItem label="Prism Launcher">
1. Download, install and launch [Prism Launcher](https://prismlauncher.org/)
2. Click `Add Instance`
3. Select `Curseforge` tab from the left
4. Search "HMT Pack"
5. Click `OK`
   * Optional: Select the version you want by selecting it on the dropdown before you click `OK`.
6. The modpack will now install.
7. Once installed, double-click the icon to play.
  </TabItem>
