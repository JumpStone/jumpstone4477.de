import { LinkCard, Aside } from "@astrojs/starlight/components";

A simple texture pack that turns the desired normal and deepslate ore Block completely green. No other changes made. Perfect for much better visibility and compatible with all Minecraft versions.

<Aside type="tip">
  If you are red-green colorblind (Protanopia & Deuteranopia) we recommend [JS
  Cyan Ores](/projects/ressourcepacks/js-cyan-ores/) for you.
</Aside>
