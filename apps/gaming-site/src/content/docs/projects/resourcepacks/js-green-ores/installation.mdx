## Installation

<Tabs>
  <TabItem label="CurseForge">
  <Aside>
  Some resource packs haven’t been approved by CurseForge yet, so you can’t download them right now. You can find a list at the top of this website to see which version is available on CurseForge.
</Aside>

  <Tabs>
  <TabItem label="On the app">
1. Open CurseForge App
2. Go to `My Modpacks`, click on the modpack you want to add a JS Green Ore resource pack to.
3. Click `⫶` (three dots) → `Profile Options`
4. Check "Allow content management for this profile", click `Done`
5. Click `🧩` (puzzle icon)
6. Search for "JS Green `ore` Ore" (replace `ore` with the ore block you want to replace). Then click `Install`
7. Run the game by clicking `Play`. You should now have the new resource pack(s) installed!  
</TabItem>
  <TabItem label="On the website">
1. [Open CurseForge search](https://www.curseforge.com/minecraft/search)
2. Search for "JS Green `ore` Ore" (replace `ore` with the ore block you want to replace) OR click on the `CurseForge` button under the Block you want to replace.
3. Click `Install`
4. Select the modpack you want to add a JS Green Ore resource pack to, click `Install`
5. Run the game by clicking `Play`. You should now have the new resource pack(s) installed!  
</TabItem>

  </Tabs>
  </TabItem>
  <TabItem label="Modrinth">
  <Tabs>
    <TabItem label="On the app">
1. Open Modrinth App
2. Open `|||\` "Library"
3. Click on the modpack you want to add a JS Green Ore resource pack to.
4. Click `🧭 Browse content`
   * If you have not added any mods/resource packs/etc., the button will be at the bottom center, otherwise right below the header
5. Search for "JS Green `ore` Ore" (replace `ore` with the ore block you want to replace).
6. Click `⤓ Install`
7. Go back to `|||\` and run the game as usual. You should now have the new resource pack(s) installed!
  </TabItem>
  <TabItem label="On the website">
1. [Open Modrinth search](https://modrinth.com/discover/resourcepacks), search for "JS Green `ore` Ore" (replace `ore` with the ore block you want to replace) OR click on the `Modrinth` button under the Block you want to replace.
2. Click on the resource pack listing
3. Click `Install`, then `Install with Modrinth App`
4. Select `Existing Instance`, then click `Install`
5. Close the addition window with `X`
6. Run the game by clicking `Play`. You should now have the new mod(s) installed!
  </TabItem>
  </Tabs>
  </TabItem>
    <TabItem label="Prism Launcher">
1. Open Prism Launcher
2. Right-Click on the modpack you want to add a JS Green Ore resourcepack, then click on `Edit`.
3. Click `Resource Packs` in the left-hand menu.
4. Click `Download Packs` in the right-hand menu.
5. Search for "JS Green `ore` Ore" (replace `ore` with the ore block you want to replace).
6. Click on the box on the left site of the resource pack icon.
7. Click on `Review and confirm` then `OK`.
7. Now you can run the game as usual. You should now have the new resource pack(s) installed!
  </TabItem>

      <TabItem label="Manual setup">
1. Launch Minecraft
2. Click `Options` then `Resource Packs`
3. Click `Open Pack Folder`. The Explorer/Finder/Dolphin should open in the resourcepacks folder.
4. Download a JS Green Ore resource pack from either Modrinth or Curseforge by clicking the buttons at the top of this page below the block you want to replace.
5. Drop the downloaded zip file into the resource pack folder.
6. Go back to Minecraft and select the resource pack from the list on the left.
  </TabItem>


</Tabs>
